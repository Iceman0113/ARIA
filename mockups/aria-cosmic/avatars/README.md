# ARIA Agent Avatars — generation + drop-in

Drop the 6 finished portraits in THIS folder with these exact names:

    scout.png  hunter.png  creative.png  hermes.png  beacon.png  verse.png

Specs: square 1:1, 512–1024px, head-and-shoulders centered. Dark or transparent
background both work (the orbs crop to a circle). As soon as a file is here and you
reload the prototype, it replaces that agent's placeholder in the orb, the dock card,
and the task editor automatically. Missing files just keep the SVG placeholder.

---

## Shared style (already baked into each prompt below)
Square 1:1 portrait, head-and-shoulders bust of a glossy 3D-rendered humanoid AI robot,
centered, facing camera, premium friendly character design (Pixar-meets-sci-fi). Smooth
white/chrome body panels. Dark cosmic studio backdrop with a faint teal nebula. Soft
cinematic studio lighting with a strong RIM LIGHT in the agent's signature color. High
detail, clean, no text, no watermark.

> Consistency tip: generate all six in one session. After the first, prompt
> "same robot character design, materials and lighting as before — change only the
> rim-light color and the prop" (or reuse the same seed) so they read as one crew.
